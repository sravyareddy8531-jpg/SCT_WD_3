# Task 3 - Quiz Game Application

## 📌 Description
This project is an interactive Quiz Game Application developed as part of my internship. It displays multiple-choice questions, allows users to select answers, and shows the final score at the end.

## 🚀 Features
- Multiple-choice questions (MCQs)
- Dynamic question display
- Clickable answer options
- Automatic navigation to next question
- Final score display
- Simple and user-friendly interface

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🎮 How to Use
1. Open the application
2. Read the question carefully
3. Click on the correct option
4. The next question will appear automatically
5. At the end, your total score will be displayed
